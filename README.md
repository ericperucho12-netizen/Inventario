# Inventario - PeruchOS

Sistema de punto de venta (POS) y gestión de inventario.

## Estructura del Proyecto
- `apps/desktop-pos`: Aplicación de escritorio y móvil (React, Vite, Electron, Capacitor, TailwindCSS).
- `packages/backend-api`: API backend (NestJS, TypeORM, PostgreSQL).
